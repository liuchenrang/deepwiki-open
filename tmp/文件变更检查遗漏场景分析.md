### 2.2 边界情况遗漏

#### ❌ 场景 5：Commit 历史重写（Rebase/Squash）

**操作**：
```bash
# 修改历史提交
git rebase -i HEAD~3
# 或者
git reset --soft HEAD~2
git commit -m "Squashed commit"
```

**问题**：
```python
# git_utils.py:265-270
current_hash = get_current_commit(repo_path)

if previous_hash is None:
    previous_hash = get_previous_commit(repo_path)
    # previous_hash = "abc123"

# 用户执行 git rebase
# current_hash = "def456" (新的 commit hash)
# previous_hash = "abc123" (旧的 commit hash)

# ❌ 问题：abc123 已经不在历史中了！
# git diff abc123..def456 会失败或返回错误结果
```

**当前代码处理**：
```python
# git_utils.py:299-303
result = run_git_command(
    repo_path,
    ["diff", "--name-status", f"{previous_hash}..{current_hash}"],
    check=True  # ❌ 会抛出异常！
)

# 异常处理：
# git_utils.py:359-363
except Exception as e:
    logger.error(f"Failed to detect changes: {e}")
    logger.warning("Falling back to full refresh due to error")
    is_initial = True  # ✅ 会降级为全量处理
```

**影响**：
- ✅ 会被捕获并降级为全量处理
- ⚠️ 但会丢失增量更新的优势
- ⚠️ 所有文件都需要重新生成向量

**优化方案**：
```python
try:
    result = run_git_command(
        repo_path,
        ["diff", "--name-status", f"{previous_hash}..{current_hash}"],
        check=True
    )
except Exception as e:
    logger.warning(f"Failed to diff {previous_hash[:8]}..{current_hash[:8]}")

    # 检查是否是历史重写
    result = run_git_command(
        repo_path,
        ["merge-base", previous_hash, current_hash],
        check=False
    )

    if result.returncode == 0:
        # 找到共同祖先
        base_hash = result.stdout.strip()
        logger.info(f"History rewritten, using base commit: {base_hash[:8]}")

        result = run_git_command(
            repo_path,
            ["diff", "--name-status", f"{base_hash}..{current_hash}"],
            check=True
        )
    else:
        # 完全找不到共同祖先，降级为全量
        is_initial = True
```

```python
# pgvector_backend.py 添加批量删除方法

def delete_by_metadata_batch(self, key: str, values: List[str], soft_delete: bool = False) -> int:
    """
    批量删除符合条件的文档

    Args:
        key: 元数据键
        values: 元数据值列表
        soft_delete: 是否软删除

    Returns:
        删除的文档数量
    """
    with self._get_connection() as conn:
        with conn.cursor() as cur:
            if soft_delete:
                cur.execute(
                    f"UPDATE document_chunks SET deleted = TRUE WHERE {key} = ANY(%s)",
                    (list(values),)
                )
            else:
                cur.execute(
                    f"DELETE FROM document_chunks WHERE {key} = ANY(%s)",
                    (list(values),)
                )

            deleted_count = cur.rowcount
            conn.commit()

    logger.info(f"Batch deleted {deleted_count} documents where {key} IN ({len(values)} values)")
    return deleted_count
```
